# Angela & John Wedding Website

An elegant, responsive one-page wedding website for Angela and John's wedding on 29 December 2026.

## Preview locally

Open `index.html` directly in a browser, or run any static file server from this folder. For example:

```bash
npx serve .
```

## Before publishing

1. Replace the three Unsplash image URLs in `index.html` with the couple's real photographs.
2. Replace both placeholder phone numbers in the contact section, including the `tel:` and `wa.me` links.
3. Confirm the Google Maps search results for the church and reception venue.

The website is static and can be deployed to GitHub Pages, Netlify, Vercel, or any standard web host.
